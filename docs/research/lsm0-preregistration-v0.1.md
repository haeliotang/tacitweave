# LSM-0 preregistration v0.1 (draft)

日期：2026-11-13。状态：**未提交、未获伦理批准、不可用于招募**。
这是把当前方法学结论写进一个可审查的草案，不是注册记录。

## 0. 决策门

在人类数据采集前必须满足：

- Gate 2A 真实设备管线通过；
- Gate 2B 测量有效性通过；
- 本草案中的主要分析与区间方法通过预先指定的校准模拟；
- 伦理批准与知情同意版本冻结；
- 研究存储生命周期通过合成/真实撤回测试。

如果区间方法仍未通过校准：

## 2. 研究问题

**主要问题**：在明确同意、纵向重复 session 下，预先指定的生理特征与自报经验之间是否存在可复现的个体内关联？

**表示问题（A）**：身体、意象、关系瞬间与主动行为能否在来源可审计的表示契约下被稳定记录，而不被系统解释替代？

**增量问题（C）**：在 X + H 之外，直接主动行为 A 是否对未来的独立结果 Y_future 有样本外增量价值？

不检验：

- 潜意识读取
- 临床诊断/治疗
- 情绪分类准确率作为构念效度
- 公开数据上的 Tacitweave 假设

## 3. 假设与失败条件

### H1（B 的个体内关联）

- H1：预先指定的信号特征与自报变量在个体内存在正向关联。
- 失败：关联不超过保留时间结构的阴性对照，或在预注册排除规则下消失。

### H2（阴性对照）

- 时间结构保留对照（circular shift / block / phase）不应产生同等强度关联。
- 失败：对照与主分析不可区分。

### H3（阳性对照）

- paced breathing 或设备支持的其他已知操作应改变相应生理特征。
- 失败：管线对已知变化不敏感。

### H4（C 的增量）

- 在 X + H 基线上加入直接用户行为 A，预注册测试窗口的样本外误差有稳定改善。
- 失败：无改善、只在泄漏条件下改善、或 A 是 X/H 的确定性函数。

### H5（A 的表示）

- 重复 probe 的表示一致性与修订率可被稳定测量；来源不能被静默升级。
- 失败：来源不可审计、确认目标不一致、或结果完全由 prompt/layout 解释。

## 4. 设计

- 个体内、纵向、重复 session。
- 参与者数/session 数：**由精度模拟决定，不先写漂亮数字**；现有模拟场景 12–24 参与者 × 8–12 sessions 仅是设计探索范围，不是功效声明。
- 设备/固件：Gate 2A 选定后冻结；未选定前不招募。
- 特征版本：冻结并记录 commit。
- 研究数据与产品摘要分离。

## 5. 变量

### 表示变量

按 `representation-contract-v0.1`：

- 身体位置、感觉、强度、呼吸、意象碎片、关系瞬间、主动行为；
- 每条记录带 `source`、revision、generator/basis/confirms（适用时）。

### 信号变量

预注册后冻结，例如：

- ECG 心率/HRV（具体特征待 Gate 2B 决定）；
- EDA 水平/反应性；
- 呼吸率/变异性；
- 不事后遍历所有通道。

### 自报变量

- 强度；
- 确定度；
- 主动行为后的独立结果（预注册）。

## 6. 主要估计量

候选：**参与者内 Spearman 相关**，再汇总为组均值。

但当前审计显示：

- participant-level bootstrap 覆盖不足；
- moving-block bootstrap 更差；
- participant-cluster bootstrap 也未通过覆盖审查。

因此本草案**不批准**上述任一区间方法。Fisher-z 随机效应候选加入显式 effectivePairs（AR-adjusted）后，在模拟中接近/超过名义覆盖，但区间更宽、AR=0.8 仍有 bias；仍不是批准方法，需真实特征与第二分析者校准。

**暂定 AR 门槛（未冻结）**：

- 对每个参与者的 primary signal 和 self-report 分别估计 lag-1 自相关；
- 若 median |AR| > 0.5，停止使用随机效应推断，只报告描述性估计与敏感性；
- 若 median |AR| ≤ 0.5，仍须在实际 session 数下重跑 coverage 模拟，才可使用候选区间；
- 门槛必须在 Gate 2B 后用真实特征重新校准，不能因为本模拟好看就固定 0.5。

分析计划必须包含：

1. 估计量的偏差（observed vs simulation target）；
2. 区间覆盖率校准；
3. 失败场景；
4. 若校准失败，降级为描述性报告。

## 7. 对照

- 简单打乱（仅 sanity check）；
- circular shift / block / phase（主阴性对照候选）；
- 设备关闭/无信号（如可行）；
- paced breathing 阳性对照；
- 对照参数、seed、block length 预注册。

## 8. 分析计划

- 每个参与者单独估计，不把组间相关当作个体结论；
- 缺失按预注册 pair 排除，不插补；
- 质量排除规则冻结；
- 不报告 p 值，除非另行预注册；
- 多重比较/停时规则预注册；
- 独立分析者或盲法流程；
- 代码 commit、数据 hash、manifest 冻结。

## 9. 样本量与精度

- 使用 `pnpm lsm0:precision` 和 `pnpm lsm0:method-audit` 做设计模拟；
- 报告 interval coverage、bias、width、可评估率；
- 不以“p<0.05”作为样本量依据；
- 如果无法得到可校准区间，主要分析改为描述性/估计报告。

## 10. 数据管理

- 原始信号单独同意；
- 研究存储使用独立于产品摘要的加密存储；
- 撤回即停采、删除密钥、重启无残留、备份副本边界；
- 留存期限与删除证明；
- 数据字典与 manifest。
