# Gate 2A/2B checklist

日期：2026-11-07。状态：可执行检查清单；真实设备接入前先跑 SIL。

## Gate 2A — Pipeline validity

### 设备与出处

- [ ] 厂商、型号、硬件 revision
- [ ] 固件版本（精确字符串）
- [ ] 驱动/SDK 版本
- [ ] 采样率、通道数、通道名称/单位
- [ ] 电极/传感器位置与接触方式
- [ ] 设备序列号哈希（不存明文序列号）
- [ ] 设备时钟来源（设备时钟/主机到达时间/两者）

### 时间与完整性

- [ ] 设备时钟与主机时钟的 offset 已记录
- [ ] 采样率漂移/抖动范围
- [ ] 丢包、重复包、乱序包计数
- [ ] 最大间隔、>1s 间隔数
- [ ] session 开始/结束/暂停/恢复
- [ ] 时间戳单调性检查
- [ ] 跨设备对齐检查（若有多设备）

### 故障恢复

- [ ] 已知注入丢包（SIL）
- [ ] 已知注入抖动（SIL）
- [ ] 已知注入连续 outage（SIL）
- [ ] 真实断开
- [ ] 自动重连与重连次数
- [ ] 应用重启后的恢复/不恢复
- [ ] 撤回后摘要与原始数据（如保存）都删除
- [ ] 回放/导出可重算

### 通过标准

- [ ] 所有异常都有显式标记，不被静默丢弃
- [ ] 真实设备至少连续 3 次 session 完成上述测试
- [ ] 记录设备/固件/时钟/质量证明
- [ ] 失败场景有可复现日志

## Gate 2B — Measurement validity

- [ ] 特征提取版本/参数冻结
- [ ] 独立第二人从留存数据重算同一特征
- [ ] 传感器质量指标与排除规则预注册
- [ ] 重测稳定性（同状态/同设备重复）
- [ ] 已知阳性对照（如 paced breathing）检出预期方向
- [ ] 阴性/无信号条件不产生同等关联
- [ ] 伪迹/运动/接触不良标记
- [ ] 缺口处理、滤波、采样率敏感性分析
- [ ] 原始数据或可重算数据留存策略与单独同意
- [ ] 产品摘要与研究原始数据分离

### 通过标准

- [ ] 特征可由第二人复算
- [ ] 阳性对照方向符合预注册
- [ ] 排除规则在看过主要结果前冻结
- [ ] 质量差的 session 不会被静默纳入主要分析
- [ ] 若不保存原始数据，明确声明摘要不足以支持可复现研究

## SIL / HIL 命名

- 真实设备进入前：**SIL**（Software-in-the-Loop）
- 真实设备接入后：**HIL**（Hardware-in-the-Loop）
- 两者共用协议和断言；SIL 通过不等于 HIL 通过
