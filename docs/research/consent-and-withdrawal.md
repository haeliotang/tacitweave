# Consent and withdrawal

日期：2026-11-01。状态：本机原型；研究用正式同意尚未开始。

## 本机原型

- 默认不上传、不建账号、不联网同步。
- 麦克风只在用户点击测量后开启；只保存音量/停顿摘要，不保存原始音频。
- BCI 设备桥接只接受本机 `127.0.0.1` 连接，并要求启动时生成的 token。
- 任何信号 session 只保存摘要；用户可以删除全部本机数据。
- 应用锁开启时，本机 snapshot 以 AES-GCM 加密保存；这只是本机保护，不是系统锁屏或远程加密。

## 明确同意

每个敏感能力必须单独同意，而不是藏在总协议里：

1. 本机麦克风测量
2. 本机设备桥接连接
3. 未来任何云端/世界模型请求
4. 未来研究数据采集

同意记录必须包含用途、时间、版本；撤回后停止新采集，并提供删除入口。

## 撤回与删除

- 删除本机数据：设置页「删除全部本机数据」。
- 删除是覆盖/移除，不是隐藏；浏览器回退数据与 SQLite 都清除。
- 已导出的 JSON 文件由用户自行保管，应用无法远程删除。
- 研究场景必须提供退出、删除、联系人与不良事件流程；本仓库当前不包含这些机构流程。

## 第三方与临床边界

- 关系触发点只记录用户自己的描述；不要写对方真实姓名。
- 不推断对方、不做匹配、不做依恋类型分类。
- 不用于临床诊断、治疗、危机干预或记忆恢复。
- 强烈痛苦、自伤/他伤风险时停止使用并寻求现实支持。
