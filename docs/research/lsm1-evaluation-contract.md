# LSM-1 evaluation contract

日期：2026-11-13。状态：评估契约；没有训练或验证任何 LSM-1 模型。

## 目标

定义“未来的纵向模型是否真的有增量价值”，而不是先训练一个看起来会预测的模型。

核心问题：

> 在已知身体输入 X、历史 H 之后，象征空间中的主动行为 A 是否对未来的独立结果
> Y_future 提供额外预测价值？

## 符号

- **X**：同一时点的身体、意象、关系输入。
- **H**：该参与者此前的记录/自报历史。
- **A**：进入象征空间后的主动行为观测（靠近、停留、离开、再次进入等）。
- **Y_future**：在 A 之后独立采集的结果（下一次自报、退出/回访、独立问卷等）。

最小比较：

```text
baseline:      Y_future ~ X + H
full:          Y_future ~ X + H + A
```

只有 `full` 在**固定时间切分**的样本外评估中稳定优于 `baseline`，才可能支持 A 的增量价值。

## 主动行为必须是新观测

A 必须满足：

- 用户直接操作，不是系统推断的“停留即靠近”；
- 有独立时间戳，位于 X/H 之后、Y_future 之前；
- 不被写回 X；不把 A 派生的 symbolic parameter 再当作 A；
- 有行为记录协议，说明 UI 布局/提示是否影响可观察性。

如果 A 是确定性 `A=f(X,H)`，则不能声称它带来新信息；最多是表示效用。

## 时间隔离与信息泄漏

必须固定：

- 训练/验证/测试按时间切分，不能随机打乱同一参与者的未来到过去；
- 特征标准化只用训练窗口；
- 超参数选择只看验证窗口；
- 缺失插补不跨未来；
- 评估 target 在 A 之后才可获得；
- 不用未来 session 数量/退出结果来构造过去特征。

## 基线

至少包括：

1. 常数均值
2. 上一次自报（last history）
3. X + H 的无交互模型
4. 非交互式基线（没有主动行为）
5. session 序号/时间趋势（如适用）

可选：简单线性/混合模型。复杂模型只有在样本外优于基线时才值得保留。

## 合成数据反例

在真实数据前，用完全合成轨迹检查评估程序：

- **植入关联**：A 对 Y 有真实增量；程序应检出。
- **伪关联**：A 只是 X 的确定性函数；程序不应把它当成新信息。
- **时间泄漏**：把未来信息泄漏到特征；程序必须报错或检出异常。
- **过拟合**：A 与 Y 在训练集偶然相关、测试集消失；程序应拒绝。
- **缺失机制**：缺失与结果相关；程序应报告敏感性，不能静默完整案例分析。

## 评价指标

- 样本外误差/校准（按任务预注册）
- 相对 baseline 的增量与不确定性
- 每个参与者的方向/异质性
- 失败率、覆盖率和排除率
- 计算成本与可复现性

不报告 p 值除非预注册；不以单个显著结果替代复现。

## 决策规则

- 合成数据不能检出植入关联 → 评估程序失败，不进入真实数据。
- 合成数据接受伪关联 → 评估程序失败。
- 真实数据只在预注册测试集上评估一次；不得反复调参。
- 增量只出现在泄漏/事后选择条件下 → 结论为无增量。
- 不训练/发布“潜意识识别模型”。
