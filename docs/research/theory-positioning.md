# Theory positioning

日期：2026-11-06。状态：项目内部理论定位；不是临床或意识理论定论。

## 一句话

Tacitweave 研究的是**前语言的身体—意象—关系预测模型**，以及用户如何在可退出的象征空间中主动采样、命名和修改它；不是读取或解码深层潜意识。

## 三个理论锚点

- **Friston / active inference / interoception**：身体感受与情绪是推断和构建，不是直接读数；精度、不确定性和预测误差是核心变量。
- **Levin / TAME / bioelectricity**：身体与自我边界可以放在多尺度 agency 视角下理解；但 TAME 不是人类 subconscious 的证据。
- **Yamanaka / iPS**：细胞身份具有可塑性；但细胞重编程不能外推为心理/意识“重编程”。

## 项目中的翻译

| 文献概念 | 项目中对应 | 不声称 |
|---|---|---|
| interoceptive inference | 躯体地图、感觉、强度、呼吸 | 不是生理读数 |
| constructed emotion | 用户自己命名/修改感受 | 不是情绪识别 |
| controlled imagination | 可进入/退出的象征空间 | 不是潜意识解码 |
| Markov blanket / self boundary | 本地数据、退出、撤回、删除 | 不是系统定义用户自我 |
| multiscale agency | 身体与关系层的目标/边界 | 不是对他人推断 |
| cell plasticity | 状态可变、标签可修改 | 不是心理创伤重置 |

## 研究问题

1. 同一参与者的身体—意象—关系组合在纵向 session 中是否有稳定性？
2. 某些信号摘要与躯体自报强度/呼吸是否存在可复现的个体内关联？
3. 象征空间参数是否与身体—意象模式存在描述性对应？
4. 加入不确定性/精度后，上述关系是否更可解释？
5. 主动选择（靠近/停留/离开）与后续自报变化是否相关？

## 明确边界

- 不做诊断、治疗、记忆恢复或临床有效性声明。
- 不把 FEP 当成意识理论已解决。
- 不把 TAME/生物电当成人类潜意识证据。
- 不把 Yamanaka 的 iPS 重编程当成心理治疗。
- 不把关系拓扑用于推断对方、依恋类型或人格。
- 不把停留时长、信号强度、象征空间体验包装成“潜意识读数”。
