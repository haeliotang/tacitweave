# LSM-0 protocol v1（审阅稿）

日期：2026-11-07。状态：**内部审阅稿；尚未伦理批准、尚未预注册、尚无参与者数据。**

> 这不是临床方案，也不证明“前语言心理结构”。
> Measurement validity is not construct validity.

## 1. 研究问题

在真实设备、真实自报与可审计的纵向 session 中：

> 预先指定的生理信号特征，是否与同一参与者的自报躯体强度/确定度存在超过预定义阴性对照的个体内关联？

不回答：

- 是否读取潜意识
- 是否诊断
- 是否临床有效
- 是否可泛化到所有设备/人群/场地

## 2. 设计

- 个体内、纵向、重复 session
- 计划：12 名参与者 × 8 次 session 仅作为**模拟起点**；最终 N/session 数在精度模拟、敏感性分析和方法选择后固定。当前不冻结 12×8 设计。
- 每次 session：标准化身体捕获 + 可选信号 + 象征空间 + 自报
- 设备/固件/特征提取版本锁死
- 分析与采集分离

这是**先导研究**，不是确证性试验；不提供临床结论。

## 3. 参与者

- 成年人，能够理解并自愿同意
- 排除：当前急性危机、无法安全使用设备、研究者判断不适合
- 退出：任何时间无理由退出；已采集数据按同意范围删除
- 不招募无法提供独立同意的人

## 4. 测量

### 自报（主要）

- 躯体强度（1–5）
- 确定度（clear/mixed/unsure）
- 可选：主动选择（靠近/停留/离开）次数与时机

### 信号（候选，Gate 2B 后冻结）

- 心率 / HRV 特征
- EDA 特征
- 呼吸特征
- 设备质量标记
- 只使用 Gate 2B 通过后冻结的特征；不事后新增通道

### 符号参数

- `format`、`motifs`、`figure`、agency 事件
- 只作为次要/探索变量，除非预注册为 L4 任务输入

## 5. 主要终点与估计

- 主要估计量：每个参与者的 session 级信号特征与自报强度的个体内关联
- 报告每个参与者的点估计与预注册的区间估计；普通 bootstrap 不能默认适用，需与 non-circular moving-block/其他保留时间结构的方法比较；当前 precision 模拟显示 12×8 的区间较宽，不能把 12×8 当成已足够
- 不将 group median 作为个体结论
- 不以 p 值筛选“显著参与者”
- 预注册固定排除规则与缺失处理

### 通过标准（必须在预注册中冻结）

- 最低有效 session 比例
- 最低可评估参与者数
- 主要关联方向/效应量阈值
- 置信区间/不确定性要求
- 阴性对照比较方式
- 阳性对照方向
- 安全/退出无严重问题

v1 不在未看数据前伪造最终阈值；预注册时必须写死，且不得事后调整。

## 6. 对照

- 简单打乱信号（sanity check）
- **保留时间结构**的阴性对照：块置换或相位随机化（与采样机制匹配）
- 设备关闭/无信号条件
- 阳性对照：paced breathing 等已知变化
- 阴性结果完整报告

## 7. 分析计划

- 主要：个体内关联 + 预注册区间估计（优先保留时间结构的方法；普通 bootstrap 仅作对照）
- 次要：多水平模型/敏感性分析（预注册）
- 缺失：不插补；报告缺失与排除
- 质量：按 Gate 2B 的质量规则排除，规则预注册
- 多重比较：预注册主要/次要，其余标探索
- 不把相关性解释为因果或临床有效性

## 8. 构念效度

即使关联复现，也只能说可观测变量相关。要讨论“前语言结构”，必须额外：

- 预先指定构念定义
- 区分效度：与一般唤醒/压力/运动/期待等替代解释比较
- 混杂控制
- 增量预测价值
- 独立复现

## 9. 数据管理

- 研究原始数据与产品摘要分离
- 单独同意、加密访问、留存期限、撤回/删除记录
- 不默认永久保存高度敏感原始信号
- 不把不可复算摘要当作研究可复现数据
- 数据管理计划随伦理提交

## 10. 安全

- 随时退出
- 急性痛苦/自伤/他伤风险时停止并寻求现实支持
- 设备安全与中止规则
- 不良事件记录
- 研究者联系方式与转介流程

## 11. 偏离与停时

- 方案偏离记录并报告
- 预先定义停时规则
- 先导失败不得改写成“个体差异”
- 若 Gate 2B 失败，不进入人类数据采集
