# Space Composer v0.1

日期：2026-11-14。状态：产品候选；不是科学有效性声明。

## 目标

让用户从少量非语言输入出发，自己决定象征空间里有什么，而不是只接受系统从
capture 推导出的固定空间。

## 行为

在片段详情中选择「自定义空间」，用户可以：

- 选择 1–3 块意象；
- 选择是否出现形象，以及形象类型；
- 选择 75 秒相遇、180 秒空间或开放空间（不自动结束）；
- 进入前查看当前选择。

系统只根据选择组合空间参数：

- `motifs`
- `figure`
- `durationSec`
- 相应的 space/figure prompt
- 180 秒时使用单个 `pause` beat

## 用户控制

- 不自动追加用户没有选择的意象；
- 不把用户的选择解释成情绪、记忆或诊断；
- 不根据选择生成“更懂你”的建议；
- 不保存为心理学测量；
- 随时可以关闭自定义并返回原片段。

## 边界

- 这是空间组合，不是象征意义解释；
- 不是临床工具；
- 不证明产品帮助人表达前语言经验；
- 不改变 LSM 研究的 blocked 状态。

## 验证

- `space-composer` 单元测试覆盖 75/180、1–3 意象、figure、空选择与非法时长；
- E2E：从示例片段打开详情 → 自定义空间 → 选择 Door/180 秒 → 进入空间；
- 原有连续性/关系 E2E 继续通过。
