# Familiweave v0.1.2 (now Tacitweave)

Research prototype release. **Signing is not complete for this tag.**

## Status

- Linux AppImage/DEB: unsigned.
- Windows NSIS: unsigned (the optional Authenticode step was skipped because no certificate secret is configured).
- macOS: not attached to this tag; the local Developer ID build is un-notarized and is not a substitute for a signed/notarized release.

Do not describe this release as signed, notarized, or clinical software. Gatekeeper and SmartScreen warnings are expected.

## Highlights

- SQLite schema v2 with capture provenance and signal-session v2 summaries.
- Canonical SQLite/Web state reconciliation and encrypted-state overwrite guard.
- BCI reconnect/backoff, jitter/gap health, deterministic replay and session retraction.
- 30/90-day relationship topology comparison and desktop minimum-window layout QA.
- LSM-0 offline baseline with symbolic-space metrics and local-dataset export.
- English-first README.

## Follow-up

A fully signed/notarized release still requires Apple Developer ID + notary credentials and a Windows Authenticode certificate. When those are configured, produce a new version rather than overwriting these assets.
