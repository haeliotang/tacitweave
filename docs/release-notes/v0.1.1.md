# Familiweave v0.1.1 (now Tacitweave)

Research prototype release. This build is **unsigned / ad-hoc signed**:
macOS is ad-hoc and not notarized; Windows and Linux are unsigned. Signing and
notarization remain pending external certificates.

## Highlights

- Enterable Field with drag, zoom, user-authored links, time filter and demo field.
- Optional app lock: PBKDF2 PIN verifier, AES-GCM encrypted local snapshot, idle
  auto-lock (1/5/15 minutes or never) and a 30-second lockout after five failed PINs.
- Passphrase-encrypted portable backups (PBKDF2 + AES-GCM) alongside plaintext
  v1/v2 export and import.
- WCAG A/AA accessibility checks across the main views and both light/dark themes.
- Local BCI-3 token-authenticated WebSocket bridge; no cloud sync or account.
- Explicit GitHub Releases update check; automatic updater installation is not enabled.
- English-first README; Chinese documentation is in `README.zh-CN.md`.

## Assets

- macOS Apple Silicon: `Familiweave-v0.1.1-macos-arm64.zip`
- Windows x64: `Familiweave_0.1.1_x64-setup.exe`
- Linux x86_64: `Familiweave_0.1.1_amd64.AppImage` and `.deb`
- `SHA256SUMS.txt`

Verify downloads with `SHA256SUMS.txt`; do not treat this prototype as a medical
device, diagnosis, therapy or validated memory-recovery tool.
