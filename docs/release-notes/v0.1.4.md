# Tacitweave v0.1.4 (AGPL layered licensing release)

> Status: **released**. First Tacitweave release under the layered
> AGPL-3.0-or-later / Apache-2.0 / CC-BY-4.0 terms. Linux and Windows assets
> are **unsigned**; the macOS signed asset is not part of this automated build.

## Changes since the archived v0.1.1/v0.1.2 line

- Product and bundle identity: **Tacitweave**, `com.inceptless.tacitweave`.
- Local-first symbolic field for pre-verbal bodily, imaginal and relational
  experience; no cloud sync, diagnosis or inference about other people.
- Data protection and local data lifecycle hardening, including app lock,
  encrypted backup, deletion, and migration from the former local namespace.
- Optional signal research surface, device bridge and reproducible offline
  LSM-0 tooling; these remain research tools, not clinical instruments.
- Layered licensing: AGPL-3.0-or-later for application/runtime, Apache-2.0 only
  for `docs/evaluation/experiment-log.example.json`, CC-BY-4.0 for docs, and
  separate terms for brand assets.
- CLA 1.0 replaces DCO; PRs merge only after the `license/cla` check passes.
- The desktop Settings page includes a Source link for the running version.

## Assets

- Linux: AppImage and DEB
- Windows: NSIS installer
- `SHA256SUMS.txt`

There is no macOS asset in this tag build. The macOS Developer ID workflow is
manual and requires signing/notarization credentials.

## Known limitations

- Linux and Windows assets are unsigned: Gatekeeper/SmartScreen warnings remain.
- No updater is enabled.
- Research prototype, not for clinical use.
- Signal/BCI features are optional research tools; no real-device Gate 2A
  validation is claimed by this release.
