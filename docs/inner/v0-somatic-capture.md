# v0：躯体地图 + 意象碎片

日期：2026-11-01。状态：本地原型已实现。

## 1. 目标

v0 只验证一件事：

> 当用户不用打字、只做身体定位与意象选择时，是否更接近那个“说不清”的东西？

它不是 LSM，不是潜意识读取，也不是治疗。

## 2. 交互

1. 在身体地图上点按最明显的位置：头、下颌、喉咙、肩、胸口、胃/腹、后背、手、腿。
2. 选择感觉：压迫、沉重、空/坠、绷紧、发麻、发热、发冷、麻木；强度 1–5；呼吸：屏住、很浅、偏快、很深、还算均匀。
3. 从 8 块抽象意象中选 1–3 块（黄昏楼梯间、潮湿走廊、冰冷注视、窗边雨、空站台、半开暖门、森林边缘、镜子的房间）。
4. 生成一段 75 秒 symbolic 相遇；可进入、停留、离开。

全程没有文字输入框；不要求用户命名情绪。

## 3. 数据模型

- `SomaticCapture`：`region` / `sensation` / `intensity` / `breath` / `fragments`。
- `InnerPlan.somatic`：保存这次捕获，仅本地内存。
- `innerPlanFromCapture()`：把捕获变成母题、节拍、提示词与安全字段；不写回用户原文（因为 v0 本来就没有原文）。
- `createInnerCaptureEncounter()`：本地生成 `Encounter`，不经过服务端。

## 4. 不声称什么

- 不测量潜意识、不读取创伤、不做诊断。
- 不声称意象选择对应某段记忆或某个人。
- 不声称生理信号（v0 没有传感器）。
- 不声称记忆再巩固或临床效果。
- v0 本身不自动保存；v1 可显式保存在本机，刷新后保留。

## 5. 安全边界

- 不解释、不评分、不纠正。
- 意象只是“更接近/更不接近”，不是答案。
- 随时可以离开；没有 streak、没有通知。
- 若体验引发强烈不适，停止并寻求现实支持。

## 6. 评估问题

- 与文字输入相比，用户是否觉得更接近身体感觉？
- 选择过程是否让人更安全，还是更困惑？
- 用户是否感到“被系统解释”或“被系统评判”？
- 离开是否容易？是否出现“必须选对”的压力？
- 身体地图与意象库是否遗漏重要体验？是否过于引导？

## 7. 下一步

- v2：在明确同意下的多模态研究捕获；仍不做临床声明。
