# v2：关系触发点地图（用户自述版）

日期：2026-11-01。状态：本地原型已实现。

## 1. 目标

v2 只做一件事：让用户把自己注意到的“关系触发瞬间”画出来，而不是让系统推断关系模式。

它是用户自述地图，不是关系分析、依恋测试或匹配系统。

## 2. 当前交互

- 在首页「关系触发点」区域点「添加触发点」。
- 可填写：
  - 对方角色（可留空，用化名；不要写真实姓名）
  - 当时的场景
  - 那个瞬间
  - 身体位置、感觉、强度、呼吸
  - 自动反应：靠近 / 僵住 / 讨好 / 逃离 / 反击 / 麻木
- 保存后显示：
  - 一张以「我」为中心的本地关系触发点地图
  - 列表：角色、日期、场景、瞬间、身体反应
  - 描述性计数：身体位置、感觉、自动反应各出现几次；明确标注“只是计数，不是解释”
- 支持单条删除、全部删除、导出 JSON；最多 100 条。
- 只存浏览器 `localStorage`，无服务端、无账号、无同步。

## 3. 不声称什么

- 不判断对方是什么人，不推断对方动机。
- 不做依恋类型、人格、创伤或“核心情结”分类。
- 不做关系匹配、兼容度、伤口咬合评分。
- 不解释“为什么你总遇到这种人”。
- 不做诊断或治疗建议。

## 4. 安全边界

- 提醒用户不要写真实姓名与可识别第三方的信息。
- 地图节点由用户自己命名；系统不补充含义。
- 没有提醒、没有 streak、没有“关系健康分”。
- 删除即本地删除；导出是用户主动行为。
- 若关系情境涉及暴力、威胁或急性危险，应优先现实安全与专业支持。

## 5. 与 LSM 的距离

v2 仍然只有**用户自述**：没有传感器、没有跨用户数据、没有生理推断。

它验证的是：

- 用户是否愿意把“关系触发”从叙事变成结构化记录；
- 地图是否帮助看见重复，而不把重复解释成宿命；
- 结构化记录是否比自由文本更安全、更可控。

传感器、多模态对齐与临床干预仍未实现；见 [从 v0 到 LSM / 关系拓扑](../vision/from-v0-to-lsm.md)。


## 6. 理论边界复核（2026-11-06）

结合 [意识与可塑性文献简报](../research/consciousness-and-plasticity-brief.md) 与 [理论定位](../research/theory-positioning.md)：

- 关系触发点只代表用户自己的预测/先验，不是对方的模型。
- 纵向拓扑只显示用户自述记录的重复与变化，不推断依恋类型、人格、动机或因果。
- 组件固定使用“用户自述/描述性计数”语言；导出不生成对方评分。
- 任何“关系推断”需求都应先经过伦理与协议修订，而不是作为 UI 功能默认上线。
