# 内在景观：方向说明

日期：2026-11-01。状态：方向已确立，渲染器与入口仍在开发。本文定义 Tacitweave 从“缺席关系”转向“象征空间”后的产品原则；不声称任何心理疗效，也不读取或解释潜意识。

## 1. 一句话

> 为不可言说的内在经验，提供一个可进入、可退出、可自己解释的象征空间。

输入可以是一段梦、一个反复出现的画面、一种身体感觉、一个地点或一句没有上下文的话。系统把它变成 75 秒的象征空间、一个影子般的存在、几段提示词与安全约束；用户可以靠近、停留、离开，但系统不解释“这代表什么”。

## 2. 为什么是“象征”，不是“解释”

- 梦、感觉与反复意象本来就没有唯一含义；解释会制造权威，也会剥夺用户自己的理解。
- 象征空间提供的是**形式**：门、走廊、水、房子、车站、镜子、田野、光、声音、距离。
- 用户可以带着自己的意义离开，而不是带着系统的诊断离开。

## 3. 核心结构

```
一段梦/画面/感觉
        │
        ▼
InnerPlan
母题 · 75 秒情绪弧 · 影子 · 空间/声音/光/镜头提示词 · 安全约束
        │
        ▼
WorldRenderer
symbolic（相遇/空间） / genie4（以后）
        │
        ▼
75 秒内在相遇 + 捕获与出处
        │
        ▼
一个开放问题；不解释、不评分、不诊断
```

## 4. 必须坚持的边界

- **不是治疗**：不诊断、不处理创伤、不替代专业帮助。
- **不读潜意识**：不声称知道用户“真正”在想什么，不做梦的字典式解释。
- **不恢复记忆**：不暗示被压抑的记忆，不制造虚假记忆。
- **意义归用户**：系统只给空间与问题，不给结论。
- **随时可退出**：没有强制停留、没有 engagement loop、没有“对方在等你”。
- **默认本地**：梦与感觉比照片更敏感；没有明确同意不进入云端。
- **危机转介**：涉及自伤/他伤/急性创伤时，应停止体验并提示寻求现实帮助。

## 5. 与缺席主题的关系

失去、距离与关系变化仍然是重要的母题：它们都会产生无法言说的内在经验。Tacitweave 把这些经验作为象征空间的一个入口，而不是唯一入口。

## 6. 下一步

1. v0 已实现躯体地图 + 意象碎片入口；v1 已实现本机母题日记。见 [v0](v0-somatic-capture.md) 与 [v1](v1-motif-journal.md)。
2. v2 已实现用户自述的关系触发点地图。
3. v3 已实现可选的本机声音摘要；下一步是更多传感器与多模态对齐，以及空间/物件/仪式/档案形式；见 [内在体验的形式](formats.md) 与 [从 v0 到 LSM / 关系拓扑](../vision/from-v0-to-lsm.md)。
2. 为 `symbolic` 相遇原型补安全评审、可选声音与更完整的非解释性交互。
3. 用 6 个内在体验实验做小样本测试，记录共鸣、安全感、能动性与过度依赖风险。
4. 引入心理/伦理顾问后再面向真实用户。
5. Genie 4 API 可用后，用世界模型渲染梦逻辑，而不是写实人物。

## 7. 当前实现边界

- `src/inner.ts` 已提供 `InnerPlan`、母题/影子/节拍/提示词/安全字段与 `pnpm inner:storyboard`。
- `symbolic` 程序化渲染器已提供 75 秒相遇与 180 秒空间两种无声原型：可进入、靠近、停留、离开；不解释、不诊断。
- 没有临床验证、没有真人试验、没有“潜意识读取”能力。
