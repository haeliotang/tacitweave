# v1：本机母题日记

日期：2026-11-01。状态：本地原型已实现。

## 1. 目标

v1 只做一件事：让用户把 v0 里反复出现的感觉/意象，自己命名、自己留存、自己删除。

系统不推断“这个母题意味着什么”，也不做因果解释。

## 2. 当前实现

- v0 表单增加可选名字与「保存到本机母题日记」开关（默认开启，可关闭）。
- 条目只保存在浏览器 `localStorage`：`tacitweave.motifs.v1`。
- 首页显示「本机母题日记」：名字、日期、身体部位、感觉、强度、呼吸、意象碎片。
- 支持单条删除、全部删除、导出 JSON。
- 最多保留 200 条；名字截断到 60 字符；名字为空显示「未命名」。
- 没有服务端、没有账号、没有同步。

## 3. 数据

`MotifEntry`：

```ts
{
  version: 'motif-v1'
  id: string
  createdAt: string
  name: string
  capture: SomaticCapture
}
```

导出格式：`motif-export-v1`，包含导出时间与条目；不包含系统解释或评分。

## 4. 不声称什么

- 不是在识别“核心情结”或“童年模式”。
- 不把重复出现解释成因果。
- 不做关系分析、不做匹配、不做诊断。
- 不做云端备份；清除浏览器数据会丢失。

## 5. 下一步

- v2：关系触发点地图（已实现，用户自述），只记录用户主动写下的触发情境，不推断他人。
- v3：明确同意下的多模态研究捕获（传感器与自报对齐），仍不做临床声明。
