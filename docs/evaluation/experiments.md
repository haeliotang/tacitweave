# 世界模型验证实验与评分表

日期：2026-11-01。用途：Genie 4 API / Project Genie 访问开放后，按同一口径记录 6 个生成实验，避免用单次演示代替验证。实验不要求真实逝者资料，全部使用合成记忆与合成参考帧。

## 1. 六个实验模板

每个实验至少采样 3 次，记录提示词、渲染器、模型、时间、成本、失败模式与捕获 ID。先用 `pnpm inner:storyboard --fragment "…"` 导出分镜/提示词。

| ID | 实验 | 合成输入 | 重点观察 | 关联指标 |
| --- | --- | --- | --- | --- |
| X1 | 等待线索 | “他走路时总会回头等我” | 回头/等待是否稳定出现，是否被误演成普通回头 | E1/E2 |
| X2 | 修理线索 | “她喜欢修东西” | 蹲下、查看、修好是否连贯，是否穿模/漂移 | E1/E5 |
| X3 | 一般想象 | 仅照片或“他喜欢蓝色” | 是否明确降级为一般想象，不编造具体往事 | E3/E8 |
| X4 | 台词控制 | 指定一句模板台词 | 能否逐字/近义说出；语速与停顿是否可控 | E3/E4 |
| X5 | 人物连续与参考帧 | 合成人物参考图 + 一句记忆 | 75 秒内是否换脸、换声、漂移；参考帧是否只用于环境/布局 | E2/E5/E8 |
| X6 | 交互与成本 | 靠近、坐下、转身、离开 | 交互是否响应；75 秒是否连贯；单次成本/准备时长 | E5/E6/E9 |

## 2. 九项评分表（0–4）

| 编号 | 指标 | 0 | 2 | 4 |
| --- | --- | --- | --- | --- |
| E1 | 熟悉感线索 | 完全看不出 | 偶尔出现、不稳定 | 3 次采样多数稳定可辨 |
| E2 | 人物连续 | 换脸/崩坏/换声 | 有轻微漂移但可接受 | 75 秒内保持同一虚构人物 |
| E3 | 台词来源 | 编造具体往事 | 台词相关但不可控 | 只说模板台词，不编造未提供记忆 |
| E4 | 音频 | 听不清/明显不同步 | 可听清但有瑕疵 | 对话清楚、无明显不同步、水印可接受 |
| E5 | 世界连贯 | 穿地/浮空/明显漂移 | 局部瑕疵 | 75 秒 + 交互后仍稳定 |
| E6 | 交互 | 无法靠近/离开 | 部分可用 | 靠近、坐下、转身、离开均可用 |
| E7 | 出处与回放 | 无捕获/无出处 | 有捕获但缺元数据 | 提示词/模型/时间/SynthID/hash 可追溯，可回放 |
| E8 | 隐私与伦理 | 未同意上传/写实克隆 | 有标识但流程不完整 | 默认不上传、明确同意、虚构标识、可删除 |
| E9 | 成本与时长 | 不可估算 | 可估算但不稳定 | 单次成本、准备时长、失败率可记录 |

## 3. 实验日志格式

```json
{
  "version": "experiment-log-v1",
  "experiments": [
    {
      "id": "X1-wait-1",
      "prompt": "他走路时总会回头等我",
      "rendererKind": "genie4",
      "model": "genie-4-preview",
      "sampledAt": "2026-11-01T10:00:00Z",
      "scores": { "e1": 3, "e2": 3, "e3": 2, "e4": 2, "e5": 3, "e6": 2, "e7": 4, "e8": 4, "e9": 2 },
      "notes": "合成记忆；第 2 次采样漂移",
      "captureId": "capture-…"
    }
  ]
}
```

校验命令（由 Rust `tacitweave-ops` 执行）：

```sh
pnpm eval:validate path/to/experiment-log.json
```

## 4. 记录规则

- 不把演示视频、截图或“代码已经写完”当作通过。
- 失败同样入库；失败归因、复测条件与修复后结果保留。
- 每个实验至少 3 次采样；成本与时长按实际账单/计时记录，缺少依据时写 `null`，不估算成确定值。
- 真人体验、手机真机与生产部署不在本表内，需要单独验证。

评分表与方向文档保持一致；原量化门槛与未测项不因本表存在而视为通过。
