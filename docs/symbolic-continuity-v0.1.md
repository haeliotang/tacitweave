# Symbolic Continuity v0.1

日期：2026-11-14。状态：可运行的产品候选；**不是科学有效性声明**。

## 目标

让用户过去记录的身体、意象与关系经验，可以在之后被重新访问、主动修改、比较，
并保留完整历史与解释权。

这一层不依赖 BCI，也不依赖未经验证的心理推断。它只把用户已经写下的内容变成
可回溯的经验轨迹。

## 已实现

### 1. 不可覆盖的再次进入

- 从「连续性」视图选择一条已有轨迹；
- 点击「再次进入」可以修改：
  - 名字
  - 身体位置
  - 感觉
  - 强度
  - 呼吸
  - 确定程度
  - 意象碎片
  - 本次说明（可选）
- 保存后生成**新的片段记录**，原记录不被覆盖；
- 新记录带 `continuity` metadata：
  - `rootId`
  - `parentId`
  - `visit`
  - `action: re-enter`
  - 可选 `note`

### 2. 完整轨迹

- 同一 root 的所有进入按 visit 排序；
- 每条显示日期、第几次进入、可选说明；
- 原记录与后续记录都可打开；
- 删除某条记录不会编造或重写其他记录。

### 3. 用户主导的比较

- 可以选择任意两次进入；
- 只显示字段差异：名字、位置、感觉、强度、呼吸、确定程度、意象碎片；
- 不计算“好转/恶化”，不推断因果，不解释变化；
- 没有变化的字段明确显示为未变化。

### 4. 本地持久化

`MotifEntry` 增加可选 `continuity` 字段，仍使用 `motif-v1`：

- 旧的 `motif-v1` 记录继续有效；
- 导出/导入/备份包含 continuity；
- 研究导出与产品摘要仍保持分离。

## 明确不做

- 不把再次进入称为“疗愈”“整合”或“进展”；
- 不根据字段变化推断潜意识、依恋类型或诊断；
- 不自动生成解释或建议；
- 不把进入次数、停留时间当作心理学测量；
- 不宣称产品已帮助人表达前语言经验。

这些需要适当的人类参与者研究；当前只是产品交互能力。

## 验收

- `pnpm test`：continuity 单元测试覆盖根/父/visit、历史分组、字段比较；
- `pnpm e2e`：从示例场域进入连续性视图、再次进入、修改名字/说明，确认历史变为 2 次且本地片段数增加；
- 原有 24 个 E2E 继续通过；
- 无解释性文案进入导出字段。

## 后续（仍属产品层）

- 让轨迹与场域节点/关系瞬间建立显式、可删除的连接；
- 增加“靠近/停留/离开/重新进入”的行为记录，但明确其来源与时间边界；
- 动态空间的持续进入与返回；
- 以上均不改变 LSM 研究的 blocked 状态。

动态时长见 [Dynamic symbolic space v0.1](dynamic-symbolic-space-v0.1.md)。
